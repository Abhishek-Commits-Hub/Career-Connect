# CareerConnect

A responsive job application website built using HTML, CSS, and JavaScript.

CareerConnect provides a professional interface for exploring a job opportunity and submitting an application. The project focuses on responsive design, form validation, and JavaScript DOM manipulation.

## Features

- Responsive navigation bar
- Hero section with job information
- Detailed job description
- Benefits and role information
- Responsive application form
- JavaScript form validation
- Email and required-field validation
- FAQ accordion interaction
- Dynamic application preparation checklist
- Add and delete checklist tasks
- Mark tasks as completed
- Dynamic remaining-task counter
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Media Queries
- DOM Manipulation
